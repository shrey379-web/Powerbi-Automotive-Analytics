# 🚗 Car Sales Analysis Dashboard | Power BI

An interactive Power BI dashboard designed to analyze automotive sales data, company-wise income, car models, color preferences, and customer and dealer information.


## 📌 Project Overview

This project explores car sales data through an interactive business intelligence dashboard developed using Microsoft Power BI.

The dashboard provides a consolidated view of automotive metrics, enabling users to examine car counts, company performance, model-level pricing, color preferences, and customer and dealer attributes. Interactive slicers allow users to explore the data using different selection criteria.

## 🎯 Project Objectives

- Monitor key automotive sales metrics.
- Analyze annual income across reporting years.
- Compare company-wise income contributions.
- Explore car color preferences and their distribution.
- Identify top car models based on price-related measures.
- Examine customer demographics and dealer information.
- Develop an interactive dashboard for data-driven analysis.

## 🔍 Dashboard Features

### 💰 1. Annual Income Analysis

- Visualizes annual income across 2020 and 2021.
- Shows the contribution of each year to the displayed total.
- Supports comparisons across the reporting period.

### 🏢 2. Company-Wise Income Analysis

- Compares annual income across automotive companies.
- Highlights differences in company-level performance.
- Helps users explore the distribution of income across brands.

### 🎨 3. Car Color Distribution

- Analyzes the distribution of cars by color.
- Includes Pale White, Black, and Red.
- Uses a doughnut chart to visualize each category's share.

### 🚘 4. Top 5 Models by Price

Highlights five models based on the dashboard's price-related measure:

- LS400
- Jetta
- Silhouette
- Montero Sport
- Ram Pickup

This visual supports comparisons between the selected models.

### 👥 5. Customer & Dealer Analysis

The dashboard includes a detailed data table containing attributes such as:

- Company
- Customer Name
- Dealer Name
- Dealer Region
- Gender
- Color
- Body Style

These fields support record-level exploration and customer/dealer segmentation.

### 🎛️ 6. Interactive Filters

The dashboard includes slicers for:

- Color
- Company
- Model
- Month

These controls enable users to explore selected brands, models, colors, and reporting months.
